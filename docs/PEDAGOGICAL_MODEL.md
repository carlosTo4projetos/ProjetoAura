# Modelo Pedagógico - AURA

## Princípio Central
> Não adaptar o estudante ao conteúdo. Adaptar a forma de apresentação do conteúdo às necessidades de aprendizagem do estudante, preservando os objetivos pedagógicos.

## PIA - Perfil Individual de Aprendizagem
O PIA é o núcleo pedagógico do AURA. **Não é diagnóstico clínico.**

### Dimensões observadas
| Dimensão | Tipo | Faixa |
|----------|------|-------|
| Compreensão textual | Preferência (0-1) | `pref_texto` |
| Resposta a imagens | Preferência (0-1) | `pref_imagem` |
| Resposta a áudio | Preferência (0-1) | `pref_audio` |
| Resposta a vídeo | Preferência (0-1) | `pref_video` |
| Ritmo de leitura | Categórico | lento, padrão, rápido |
| Tolerância a texto | Categórico | baixa, média, alta |
| Necessidade de repetição | Booleano | sim/não |
| Preferência por exemplos | Booleano | sim/não |
| Nível de abstração | Escala (1-5) | concreto → acadêmico |

### Regras do PIA
- Nenhuma inferência clínica a partir de um único erro.
- Nenhuma característica é permanente; todas podem evoluir.
- O sistema observa padrões, nunca diagnostica.

## Níveis de Apresentação
| Nível | Nome | Descrição |
|-------|------|-----------|
| 1 | Concreto | Imagem + frase curta + exemplo |
| 2 | Concreto explicado | Conceito + exemplo cotidiano |
| 3 | Intermediário | Conceito + exemplo + situação-problema |
| 4 | Técnico | Conceito + aplicação administrativa |
| 5 | Acadêmico | Conceito + fundamentação + análise |

## Feedback
- Claro, curto, respeitoso, objetivo.
- Sem infantilização, sem julgamento, sem excesso de texto.
- Exemplo: "Vamos olhar novamente para a situação. Primeiro precisamos identificar o objetivo da empresa."

## Atividades Prioritárias
Associação, escolha, ordenação, completar, situação-problema, classificação, resposta curta, explicação guiada.
