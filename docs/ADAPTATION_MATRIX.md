# Matriz de Adaptação - AURA

## Estrutura
```
Característica observada → Impacto na aprendizagem → Hipótese pedagógica → Estratégia → Apresentação → Atividade → Interface → Regra da IA → Indicador de resultado
```

## Adaptações Mapeadas

### 1. Textos longos geram abandono
| Campo | Valor |
|-------|-------|
| **Característica** | Textos longos geram abandono |
| **Impacto** | Carga textual elevada impede finalização |
| **Hipótese** | Fragmentar conteúdo reduz abandono |
| **Estratégia** | Blocos curtos de texto |
| **Apresentação** | Uma ideia por tela, nível 1-2 |
| **Atividade** | Questão após cada bloco curto |
| **Interface** | Limpa, sem elementos concorrentes |
| **Regra IA** | Reduzir extensão de explicações |
| **Indicador** | Comparar taxa de conclusão antes/depois |

### 2. Baixo desempenho em conceitos abstratos
| Campo | Valor |
|-------|-------|
| **Característica** | Erros recorrentes em questões abstratas |
| **Impacto** | Dificuldade de generalização |
| **Hipótese** | Exemplo concreto facilita a ponte |
| **Estratégia** | Apresentar exemplo antes do conceito |
| **Apresentação** | Exemplo concreto → Conceito → Atividade |
| **Atividade** | Associação e situação-problema |
| **Interface** | Imagens e esquemas visuais |
| **Regra IA** | Gerar exemplos do cotidiano |
| **Indicador** | Melhora na taxa de acerto |

### 3. Bom desempenho com imagens
| Campo | Valor |
|-------|-------|
| **Característica** | Acerto acima da média em atividades visuais |
| **Impacto** | Canal visual é dominante |
| **Hipótese** | Aumentar componente visual melhora retenção |
| **Estratégia** | Priorizar imagens e fluxogramas |
| **Apresentação** | Imagem + texto curto |
| **Atividade** | Classificação visual, fluxogramas |
| **Interface** | Foco em ícones e diagramas |
| **Regra IA** | Gerar explicações com apoio visual |
| **Indicador** | Manutenção ou melhora nos scores |

### 4. Necessidade de repetição
| Campo | Valor |
|-------|-------|
| **Característica** | Múltiplas tentativas necessárias |
| **Impacto** | Retenção de curto prazo menor |
| **Hipótese** | Espaçamento e revisão auxiliam fixação |
| **Estratégia** | Revisão espaçada automática |
| **Apresentação** | Retorno periódico ao conceito |
| **Atividade** | Repetir atividade em formato variado |
| **Interface** | Indicador claro de "revisão" |
| **Regra IA** | Recomendar revisão baseada em desempenho |
| **Indicador** | Redução no número de tentativas ao longo do tempo |

## Regra Fundamental
> Nenhuma adaptação é considerada definitiva sem evidência suficiente.
> A estratégia que apresentar melhor resultado deve ter probabilidade aumentada de uso.
