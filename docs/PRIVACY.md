# Privacidade e Dados Sensíveis (Privacy by Design) - AURA

## Princípios de Privacidade
1. **Minimização de Dados**:
   - Coletamos apenas os dados indispensáveis para a experiência adaptativa de estudo.
   - Nenhum dado de diagnóstico médico, laudo ou prontuário é armazenado no sistema.

2. **Isolamento do Perfil PIA**:
   - O Perfil Individual de Aprendizagem (PIA) mapeia preferências de apresentação (ex: texto curto, apoio visual) e ritmo.
   - O PIA **não contém** classificações médicas ou diagnósticos de TEA.

3. **Biometria**:
   - A autenticação biométrica é processada unicamente pelo Sistema Operacional do dispositivo do usuário.
   - O banco do AURA não armazena digitais, fotos faciais ou mapas vetoriais de rostos.
